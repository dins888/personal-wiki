# ✨ AI 应用与智能体

智能体系统、检索增强、AI 应用平台与客户端工具。

- [AI Agent](./agent/) — 能自主规划、调用工具、完成复杂任务的 AI 系统
- [Agentic](./agentic/) — 描述 AI 系统具备自主规划、动态决策、自我纠偏能力的特质词，生成式 AI 之后的新范式标签
- [检索增强生成（RAG）](./rag/) — 将外部知识检索与模型生成相结合的技术
- [扣子（Coze）](./coze/) — 字节跳动的一站式 AI Bot 开发平台
- [Cherry Studio](./cherry-studio/) — 开源多模型 AI 聊天客户端
- [Hermes](./hermes/) — 隐私优先的轻量级 AI 聊天客户端
- [Honcho](./honcho/) — AI 原生的跨会话记忆后端，为智能体提供持久化用户建模
- [CLIProxyAPI](./cliproxyapi/) — 开源 AI CLI 代理服务器，统一 Gemini/Claude/Codex 接口为标准 API
- [OpenSpec](./openspec/) — Fission AI 开源的轻量级 SDD 框架，支持棕地项目和 20+ AI 编程助手
- [Spec Kit](./speckit/) — GitHub 官方开源的 SDD 工具包，多阶段严格流程驱动规格驱动开发
