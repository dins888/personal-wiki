## 定义

Circle（官网域名 circle.so）是一款面向创作者、教育者、教练与品牌的一站式社区管理 SaaS 平台：在一个可自定义品牌、绑定独立域名的私有空间里，把讨论区、在线课程、直播活动、聊天私信、付费会员和邮件营销整合到一起。它的核心主张与公共平台相反——社区建在"自己的地盘"上，成员数据、内容、触达渠道全部归运营者所有，不受算法分发和平台规则的摆布。注意：它与发行 USDC 稳定币的上市公司 Circle Internet Group 是两家毫无关系的公司，只是同名。

## 第一性

> 把社区从平台算法手里夺回来——创作者自己的地盘、自己的会员数据、自己的收费规则。

## 比方

> 创作者的"私人会所"：微博、抖音、Facebook 小组像人来人往的大广场——摊位免费，但谁能看到你由广场管理员（算法）说了算，会员名录也锁在人家抽屉里；Circle 是你自己盘下的会所——装修（品牌皮肤）、门票（付费会员）、活动安排（课程直播）全由你定，会员名册揣在自己兜里。

### 组合理解

"Circle" 一词本身就是产品定位：帮创作者搭建和经营"自己的圈子"。名字直白地说明了它不做内容分发、不做公域流量，只做私域社群的承载工具。官网使用 .so 域名（circle.so）一方面是域名选择，客观上也成了与同名 USDC 稳定币公司（circle.com）的区分标志。公司 2019 年创立，2020 年 8 月向公众正式发布。

## 详细说明

### 核心功能

| 模块 | 说明 |
|------|------|
| 社区空间（Spaces） | 社区的组织核心：讨论区、资源库、课程分区各自独立，可按空间分别设置访问权限与付费墙 |
| 在线课程 | 拖拽式课程构建器，与社区和访问权限系统原生打通——课程内容与学员讨论在同一屋檐下 |
| 直播与活动 | 原生直播、活动 RSVP、售票、回放与回放权限控制，无需跳转第三方会议工具 |
| 聊天与私信 | 成员间私聊与群聊，替代把社群导流到微信群/Discord 的做法 |
| 付费会员 | 会员分级、订阅制、免费试用、一次性付款；可按整个社区或单个空间设收费门槛 |
| 邮件中心（Email Hub） | 原生广播、Newsletter 与自动化邮件序列，触发条件可基于加群、上课进度、活动出席等社区行为 |
| 自动化与 AI | 工作流自动化、可训练回答成员问题的 AI Agent（高阶套餐） |
| 集成与扩展 | 开放 API、37+ Zapier 触发器、可嵌入小组件、SSO；高阶套餐提供独立品牌 iOS/Android App |
| 移动/桌面端 | 全套餐含免费原生 App，成员看到的是运营者的品牌而非 Circle |

### 创立背景：从课程平台长出的社区产品

三位创始人 Sid Yadav、Rudy Santino、Andrew Guttormsen 都来自在线课程平台 Teachable 的创始团队——Sid Yadav 从工程师/设计师一路做到产品副总裁，亲历平台创作者收入做到 10 亿美元以上、公司以约 2.5 亿美元被收购的全过程。他们观察到两个结构性缺口：

- **课程平台擅长交付内容，却不擅长建立连接**——学员之间、学员与创作者之间没有沉淀关系的地方
- **社区工具擅长聊天，却撑不起结构化学习和收费体系**

2019 年三人创立 Circle，先做价值观文档再注册公司；2020 年 8 月公开发布，早期用户包括 Pat Flynn、Ness Labs 创始人 Anne-Laure Le Cunff 等头部创作者。

### 融资与现状

- 累计融资约 3300 万美元，Tiger Global 领投 A 轮，估值约 2 亿美元；Teachable 创始人 Ankur Nagpal 也是重要天使投资人
- 截至 2026 年：ARR 超 5000 万美元，已实现盈利，团队约 280 人，服务超过 13,000 个社区运营者
- 知名客户：Jay Shetty、Tim Ferriss、Ali Abdaal（Part-Time YouTuber Academy）、Pat Flynn、Kevin Rose 等

### 收费模式

SaaS 订阅 + 交易抽成的双层结构：月费从约 89 美元起步（低档套餐有约 1000 名成员上限），专业档约 89–99 美元/月，商业档约 199 美元/月（解锁自动化、AI 与 API），另有企业档与定制档 Circle Plus（约 3 万美元/年，提供官方代建的品牌独立 App）。除订阅费外，平台对社区内交易收取 0.5%–4% 的抽成，档位越高抽成越低——这与 Skool 的固定月费、Substack 的 10% 收入分成形成不同的定价哲学。

### 竞品与定位

| 竞品 | 差异 |
|------|------|
| Discord / 微信群 | 免费聊天工具，无课程、无收费体系、无品牌定制，社区资产沉淀在平台方 |
| Facebook 小组 | 公域算法分发，触达受平台限制，无付费墙 |
| Skool | 结构极简、价格更低，功能深度与品牌定制能力弱于 Circle |
| Mighty Networks / Kajabi / Podia | 同为创作者商业平台，Circle 以社区功能深度和高端定位取胜 |

Circle 卡位"创作者经济"的高端社区市场：为目标用户是付费会员制创作者、教育品牌的运营者，提供比免费工具更完整、比课程平台更懂社区的一体化方案。

## 相关概念

- **[Discord](./discord/)**：免费语音/文字社区工具，与 Circle 常被拿来对比——Discord 胜在免费与游戏基因，Circle 胜在收费体系、课程与品牌所有权
- **创作者经济（Creator Economy）**：Circle 所在的赛道，创作者直接向粉丝收费而非依赖广告分成
- **付费会员制（Membership）**：Circle 的核心商业模式支撑——经常性收入（MRR）替代一次性售卖
- **SaaS**：Circle 自身的商业模式，按月订阅 + 交易抽成
- **私域流量**：与"公域算法分发"相对的概念，Circle 是私域运营的典型工具
