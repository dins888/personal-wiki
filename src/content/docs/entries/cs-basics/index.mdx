# 🧮 计算机科学基础

算法、数据结构、图形格式与计算机科学基本定律。

- [算法（Algorithm）](./algorithm/) — 解决特定问题的一系列明确、有限的步骤规则
- [DAG（有向无环图）](./dag/) — 由有向边组成且不含环路的数据结构，广泛用于任务调度、编译器与区块链
- [Radix Tree（基数树）](./radix-tree/) — 空间优化的前缀树，通过路径压缩实现高效键查找，广泛用于路由表和数据库索引
- [SVG（可缩放矢量图形）](./svg/) — 基于 XML 的矢量图形格式，用数学描述图形，可无限缩放而不失真
- [康威定律（Conway's Law）](./conways-law/) — 系统架构必然反映组织沟通结构的经验法则
