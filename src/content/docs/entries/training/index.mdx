# 🎓 训练与优化

模型训练、优化和数据相关的核心概念。

- [微调](./fine-tuning/) — 在预训练模型基础上用领域数据进一步训练
- [RLHF](./rlhf/) — 用人类反馈来优化模型行为的训练方法
- [数据集](./dataset/) — 用于训练和评估 AI 模型的结构化数据集合
- [方差](./variance/) — 衡量数据分散程度的统计指标，机器学习中特指模型对训练数据波动的敏感程度，诊断过拟合的核心概念
