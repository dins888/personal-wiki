# 🗄️ 基础设施与运维

容器、编排、服务器、数据库与系统运维工具。

- [Docker](./docker/) — 开源容器化平台
- [Docker Desktop](./docker-desktop/) — Docker 官方桌面应用
- [Kubernetes（K8s）](./kubernetes/) — 开源容器编排系统，自动化部署、扩缩和管理容器化应用
- [Linux](./linux/) — 开源操作系统内核，现代服务器、移动设备和嵌入式系统的基石
- [Nginx](./nginx/) — 高性能 Web 服务器、反向代理和负载均衡器，驱动全球大量高流量网站
- [Elasticsearch](./elasticsearch/) — 基于 Lucene 的分布式搜索与分析引擎，支持全文搜索、日志分析和数据可视化
- [Redis](./redis/) — 高性能内存数据结构存储，支持缓存、消息队列和实时数据处理
- [Attu](./attu/) — Apache Kafka 集群管理监控 GUI
- [MongoDB Compass](./mongodb-compass/) — MongoDB 官方图形化管理工具
- [Neo4j Desktop](./neo4j-desktop/) — Neo4j 图数据库本地图形管理应用
