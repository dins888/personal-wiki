# 💻 开发工具与工程实践

软件开发工具、协作流程与工程方法论。

- [Git](./git/) — 分布式版本控制系统
- [Pull Request（PR）](./pull-request/) — 代码审查与合并的协作流程
- [CI（持续集成）](./continuous-integration/) — 频繁集成代码并自动化构建测试的开发实践
- [IDE（集成开发环境）](./ide/) — 集代码编辑、调试、构建于一体的软件开发工具
- [Visual Studio Code](./visual-studio-code/) — 微软开源的轻量级代码编辑器
- [Postman](./postman/) — API 开发和测试工具
- [API](./api/) — 应用程序编程接口，软件系统间的通信契约
- [CLI（命令列接口）](./cli/) — 通过纯文本命令与计算机交互的界面
- [GraphQL](./graphql/) — API 查询语言和运行时，让客户端精确指定所需数据结构
- [Batch（批处理）](./batch/) — 将多个任务集中一次性执行的计算模式，从 .bat 脚本到大数据 Hadoop/Spark 全谱系
- [Python 3.1](./python31/) — Python 编程语言的 3.1 版本
- [提示工程（Prompt Engineering）](./prompt-engineering/) — 系统性地设计和优化提示词的技术
